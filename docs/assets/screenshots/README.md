## Capture standards

- Save lossless PNG files at the normal play resolution; prefer a 16:9 capture at 1920×1080 or higher.
- Use the GUI scale and recommended bindings intended for players so labels remain readable.
- Hide chat, server addresses, account names, private base coordinates, and unrelated notifications.
- Frame the relevant interface clearly. Crop only when the surrounding game view adds no useful context.
- Avoid shaders unless the screenshot is specifically demonstrating shader behavior.
- Record the pack version and capture date in the commit message.
- When embedding a capture, write descriptive alt text that explains the interface and the action being demonstrated.

The handbook contains invisible `handbook-figure` comments at the intended insertion points. Replace a marker with the finished Markdown image and update this table to `Captured`; do not embed a filename before the image exists.
